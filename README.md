# 🍅 Pomodoro Timer с анимированным LED дисплеем

Красивый помидорный таймер с плавной анимацией цифр в стиле LED дисплея на точках.

![Pomodoro Timer](screenshot.png)

## ✨ Особенности

- 🎨 **LED дисплей на точках** - цифры отображаются светящимися точками с эффектом свечения - на HTML5 Canvas
- 🎬 **Два режима анимации** - плавные переходы между цифрами (nearest и LURD), чередуются каждые 3 смены цифр
- 🖥️ **Клиентский рендеринг** — координаты точек вычисляются в браузере, не на сервере
- 🔊 **Звуковые сигналы** - оповещения при смене фазы (работа/отдых) и нажатии кнопок — Web Audio API, без загрузки файлов
- ⏱ **Помидорная техника** - 25 минут работы, 5 минут отдыха, длинный перерыв каждые 4 помидора
- 🔔 **Уведомления** - всплывающие сообщения при смене фазы
- 🌈 **Цветовые темы** — меняются в зависимости от режима (работа/отдых/пауза)
- 🌐 **Доступ по сети** - можно открыть с любого устройства в локальной сети
- ⌨️ **Горячие клавиши** - Пробел (старт/пауза), Escape (стоп)
- 📊 **Прогресс-бар** - визуальный индикатор оставшегося времени
- 👥 **Многопользовательность** — до 20 персональных таймеров одновременно
- ⚡ **Событийная модель** — нулевая нагрузка в простое
- 📊 **Оптимизированный трафик** — отправка данных только при изменениях (~1 Гц)

## 🚀 Быстрый старт

### Требования

- Python 3.8+
- pip

### Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/milicode1/pomodoro-timer.git
cd pomodoro-timer

# Создание виртуального окружения
python -m venv .venv

# Активация 
.venv\Scripts\activate

# Установка зависимостей
pip install fastapi uvicorn[standard]

# Запуск
python main.py
