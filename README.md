# 🍅 Pomodoro Timer с цифровой анимацией

Красивый помидорный таймер с анимацией цифровых часов в стиле LED дисплея.

## Особенности

- Плавная анимация перехода цифр
- Real-time обновление через WebSocket
- Настраиваемые интервалы работы/отдыха
- Уведомления и звуковые сигналы
- Отслеживание статистики
- Адаптивный дизайн

## Установка

### Локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/pomodoro-timer.git
cd pomodoro-timer

# Установка зависимостей
pip install -r backend/requirements.txt

# Запуск
python run.py
